# Security policy

This repository is a portfolio demo rather than a supported product, but security reports are welcome.

## Reporting a vulnerability

Report it privately through GitHub's **Report a vulnerability** button under the repository's **Security** tab. Please don't open a public issue. Include what's affected, how to reproduce it, and the impact you expect. You'll get an answer within a week.

## Scope

The code and configuration in this repository. Vulnerabilities in the services it integrates with (n8n, Google, Anthropic, Meta, Shopify, WordPress) belong to their own disclosure programs.
